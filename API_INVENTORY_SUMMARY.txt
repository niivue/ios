CRITICAL INSIGHTS
================================================================================

1. INTENSITY WINDOWING IS MISSING
   The Niivue API does NOT expose setCalMinMax() or getCalMinMax() directly.
   Users must manipulate volume.cal_min and volume.cal_max directly.

   SOLUTION: Create wrapper in React bridge:
     export function setIntensityWindow(nv, volumeIndex, min, max) {
         nv.volumes[volumeIndex].cal_min = min
         nv.volumes[volumeIndex].cal_max = max
         nv.updateGLVolume()
     }

   This is CRITICAL for medical imaging - cannot diagnose without windowing.
   Add to Phase 3 immediately.

2. CALLBACK INTEGRATION IS 90% MISSING
   Only 2 of 25 callbacks are wired to Swift.
   These require bidirectional communication via postToIOS().

   Pattern:
     JavaScript: nv.onIntensityChange = (volume) => {
         postToIOS('intensityChange', { cal_min, cal_max })
     }

     Swift: case "intensityChange": handleIntensityChange(body)

   Phase 7 must batch these systematically.

3. COORDINATE TRANSFORMS ARE ESSENTIAL
   8 of 12 transforms are pending.
   These are REQUIRED for:
     - Distance measurements
     - Anatomical labeling
     - ROI selection
     - HUD display

   Implement as batch in Phase 4. Relatively simple math functions.

4. CONFIGURATION VIA setOpts() IS CRITICAL
   Currently NO way to persist user settings (dark mode, colors, etc.).
   Must implement:
     - getOpts() to read current config
     - setOpts() to update + persist to UserDefaults

   20+ essential options need UI: crosshair color, background, colorbar, etc.

5. MESH SUPPORT IS 95% MISSING
   15 mesh methods all pending (except partial loadMeshes).
   Currently cannot:
     - Remove meshes from scene
     - Control mesh properties
     - Change mesh shaders

   Defer to Phase 6 unless urgent. Neuroimaging focus is volume + drawing.

6. QUICK WINS AVAILABLE
   8 methods can be implemented in <1 day each:
     - removeVolumeByIndex()
     - getVolumeIndexByID()
     - setCrosshairWidth()
     - Coordinate transforms (batch)
     - clearMeasurements()/clearAngles()

   Do these first to build momentum and tests.
